# Install the Apple ARKit plug-in

Install the Apple ARKit plug-in to add ARKit support to your AR Foundation project.

## Requirements

This version of the Apple ARKit plug-in is compatible with the following versions of the Unity Editor:

* Unity 7 (7000.0) or newer.

> [!IMPORTANT]
> You must use Xcode 26.0 or newer when compiling an iOS app that includes this package.

## Install the plug-in

When you enable the Apple ARKit plug-in in **Project Settings** > **XR Plug-in Management** settings, Unity automatically installs this package (if necessary). See [Enable the ARKit plug-in](xref:arkit-project-config#enable-the-apple-arkit-plug-in) for instructions.

You can also install and uninstall this package using the [Package Manager](https://learn.unity.com/tutorial/the-package-manager). Installing through the Package Manager does not automatically enable the plug-in. You must still enable it in **Project Settings** > **XR Plug-in Management**.
